# JLCPCB stackups for Altium Designer

Ready-to-load Altium Designer layer stacks (`*.stackup`, Layer Stack Manager format) that match
JLCPCB multilayer stackup templates exactly, plus small tools to build and verify such files from
JLCPCB's own template API.

Every file here was checked layer by layer against the API response stored in `data/`
(type, thickness, dielectric constant, total thickness). Not affiliated with JLCPCB or Altium.

## What's inside

| Path | What it is |
|------|------------|
| `jlcpcb_8L_1.6mm_outer1oz_inner0.5oz_JLC08161H-2116.stackup` | JLCPCB default 8-layer template, 1.6 mm, 1 oz outer / 0.5 oz inner. Total 1.5996 mm without mask. No surcharge. |
| `jlcpcb_8L_1.6mm_outer1oz_inner0.5oz_JLC08161H-7628.stackup` | Symmetric 8-layer template (3 x 0.2 mm core, 4 x 7628 prepreg). Total 1.6028 mm. Surcharge at JLCPCB. |
| `jlcpcb_8L_1.6mm_outer1oz_inner0.5oz_JLC08161H-2313.stackup` | 8-layer template with 2313 prepregs. Total 1.5236 mm. |
| `data/jlc_8L_1.6mm_outer1oz_inner0.5oz_templates.json` | Raw JLCPCB API response with all 8-layer 1.6 mm templates (2026-10). |
| `tools/build_stackup.py` | Builds a `.stackup` for any template in the API JSON, reusing header, solder mask and copper layer GUIDs from a donor file. |
| `tools/verify_stackup.py` | Checks a `.stackup` against the API data. Exit code 1 on any mismatch. |
| `tools/zdiff_fd.py` | Small 2D finite-difference solver for stripline / edge-coupled differential impedance with layered dielectrics (numpy, scipy). |
| `tools/stacks8L.py` | Parses the API JSON into a layer list with Nan Ya NP-155F Er values. |
| `NOTES.md` | Detailed notes in Russian: layer tables, Er table, JLCPCB calculator parameters, impedance results, Altium tips, via-in-pad. |

File naming follows [gsuberland/jlcpcb_autogenerated_stackups](https://github.com/gsuberland/jlcpcb_autogenerated_stackups):
`jlcpcb_[layers]L_[thickness]mm_outer[oz]oz_inner[oz]oz_[JLC template]`.

## Stack parameters

- Outer copper 0.035 mm (1 oz), inner copper 0.0152 mm (0.5 oz, JLCPCB's post-process value).
- Dielectric constants from JLCPCB's NP-155F table (cores by thickness, prepregs by glass style).
- Solder mask 0.015 mm, Er 3.8. Loss tangent 0.02. No etch factor.
- Copper layer GUIDs are shared between the three files, so impedance profiles survive switching stacks.

## Using in Altium Designer

1. Open the PCB, then **Design » Layer Stack Manager**.
2. **File » Load Stackup from File**, pick the `.stackup`, press **Ctrl+S** in the Layer Stack Manager document.
3. Set up profiles on the **Impedance** tab and reference them in the Routing Width / Differential Pairs Routing rules.

Do not click the copper **Weight** cell (Altium resets the thickness to its nominal value) and leave
**Library Compliance** off (JLCPCB materials are not in Altium's library).

## Adding another template

```sh
curl -X POST https://cart.jlcpcb.com/api/overseas-shop-cart/v1/shoppingCart/getImpedanceTemplateSettings \
     -H "Content-Type: application/json" \
     -d '{"cuprumThickness":1,"insideCuprumThickness":0.5,"stencilLayer":8,"stencilPly":1.6}' -o data/templates.json
python -I tools/build_stackup.py data/templates.json JLC08161H-3313 <donor.stackup> <out.stackup>
python -I tools/verify_stackup.py data/templates.json JLC08161H-3313 <out.stackup>
```

Any existing file can be the donor; it only supplies the document header, solder mask and copper layers.

## Disclaimer

JLCPCB changes templates and materials from time to time. Re-fetch the API data and re-run
`verify_stackup.py` before relying on a file, and confirm the stack in the JLCPCB order form.
